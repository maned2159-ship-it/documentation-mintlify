
🚀 Mintlify Documentation Website Clone (Assignment Project
This project is a desktop-first recreation of the official Mintlify documentation website, developed using only HTML and CSS.

The objective of this assignment is to focus on content structure, readability, layout accuracy, and visual consistency with the original website.

Original Website: https://www.mintlify.com/

📋 Assignmen…

This project was created following the given assignment guidelines:

✅ Desktop-first layout
✅ HTML & CSS only
✅ No JavaScript
✅ No Tailwind / Frameworks
✅ No Animations
✅ No AI-generated code
✅ Static documentation-style layout
✅ Focus on readability and structure
🧩 Sections Recreated
The following sections were implemented based on the assignment requirements:

Top Navigation Bar
Hero Section (Headline, Description, Email CTA, Background)
Documentation Preview Section (Static Sidebar + Content Cards)
Trusted By / Company Logos
Feature Highlights (Two-column Layouts)
Intelligent Assistant / UI Preview
Enterprise Features Section
Case Studies / Customer Stories
Final Call-To-Action Section
Footer (Company & Legal Links)
All sections were structured to closely match the original Mintlify documentation layout.
